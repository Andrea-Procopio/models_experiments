# Vision-model experiments (historical)

Early research code for experiments on geometric shape representations in vision models, including segmentation, change detection, and visualization.

This is a **historical experimental snapshot**, not a maintained software package or a complete reproduction release. For the associated research, see [*Modeling the Object Representations Underlying Human Physical Reasoning*](https://arxiv.org/abs/2602.12486).

## Contents

- `segformer/` — model-related experiments and analysis.
- `training/`, `eval/`, `viz/` — scripts for training, evaluation, and visualization.
- `data/`, `Exp3b_Images/`, `output_overlays/` — data samples and experimental outputs.
- `Makefile`, `run.sh`, `config.py` — historical execution and configuration files.

The original experiment scripts may depend on dataset paths and environments that are not available in this repository. Do not assume the commands are reproducible without adaptation.
